## 2. Digit-axis and raw-query semantics do not require an E2 frontend

For the registered direct positional decoder, source digits satisfy f_{p,i,x,j}=sum_{ell<delta} b^ell s_{p,i,x,ell,j}. With deltabar=2^k, set u_h=b^(2^h)/(1+b^(2^h)) and J=product_h(1+b^(2^h)). Then J eq(u,ell)=b^ell and

MLE(f_p;r_j,r_x,r_i)=J Raw~(r_j,u,r_x,r_i,bits(p)).

This identity holds for all valid noncanonical source digits. For b=32, delta=26, deltabar=32, every denominator is a nonzero K element (largest 2^80+1<q); delta=1 uses the empty point and J=1. Fixed K points embed into E2 unchanged. Virtual digit/polynomial holes are defined zero; they never add physical A columns or change source/path order. Different/nonseparable decoders require their actual adjoint, not this positional identity by analogy.

Convert **every** K ordinary claim to the corresponding E2 raw claim with value iota(v/J). Combine it with all applicable E2 domain endpoints and old E2 receiver pending claims **only within one identical original handle and complete RawView**. Bind all claims, roles, points, view and commitment before drawing independent E2 coefficients alpha_a. Prove

sum_a alpha_a z_a = sum_{x Boolean} Raw~(x) sum_a alpha_a eq(t_a,x)

by degree-two E2 sumcheck. The final equation is t * sum_a alpha_a eq(t_a,r*), with the one pending raw claim Raw~(r*)=t. Never divide by the terminal factor, assume it nonzero, or delete original claims. Independent coefficients contribute Lambda/q^2 and factor Lambda+1; rounds contribute 2 mu_raw/q^2 and factor 3^mu_raw. A genuinely singleton authenticated claim can bypass normalization. The old receiver and final identity source have delta=1, so ordinary and raw source views coincide there.

The native authentication map is

L_raw(s_{p,i}) = sum_{x,ell} eq(r_x,x) eq(r_ell,ell) s_{p,i,x,ell}(Y) in S_E.

It is S-linear. Retain every PB full-ring partial, both K coefficient planes, and the scalar recombination over p/i/j. Fold z=sum_{p,i} c_{p,i}s_{p,i}; impose original Az=sum c t plus L_raw(z)=sum c e, with the exact scheduled gadget decompositions. Ordinary decoded openings cannot replace this map when delta>1: G_com has digit-direction kernels, whereas raw digit queries observe them. A scalar-only response is not S-linear. Keeping frontend points in K does not remove either obstruction, because the normalizer's endpoint is generally E2.

## 5. Mixed-field error and extraction: what the existing theorem supports

Akita Corollary3.21 and Lemma3.22 explicitly permit independent coordinate sets S_{r,u}; they do not require one common scalar field. For each coordinate let d_{r,u}=k_{r,u}-1. Nested interpolation may use K coordinates in one stage and E2 coordinates later. The deterministic source-linked extractor above supplies the needed algebraic interpretation. The full tree product is

Tree=product_r b_r; b_r=1+sum_u d_{r,u} for a flat stage, and b_r=product_u(d_{r,u}+1) for a nested stage.

Complete accepting suffixes, source consistency across branches, finite fixed-depth grammar, exact conditional **whole-oracle-answer** sampling and prefix-preserving stage keys remain hypotheses. With exact-uniform K and E2 samplers, changing the earlier challenge set from E2 to K changes its denominator, not its degree/arity or tree factor. ## 6. Original K challenge field does not mean exact-uniform legacy sampling

The pinned Jolt DigestTranscript squeezes 16 bytes for both challenge() and challenge_scalar(); Fp128's scalar decoder reduces that word modulo q. Let N=2^128 and r=N-q=2^32-22537. Residues a<r have probability 2/N; the others have probability 1/N. Accordingly a degree-d bad set has mass at most

L(d)/N, where L(d)=d+min(d,r),

not d/q. For the bounded frontend degrees d<r, this is 2d/N. A common coefficient written C_common/q without this correction is invalid for unchanged modulo sampling.

Two valid choices, both still K frontends:

1. **Adopt bounded exact-uniform K sampling** as the one-limb specialization of the admitted bounded E2 sampler, with sticky rejection, exact conditional tapes and semantic vector boundaries. Use it for both accumulation and the matching K control. Then §5 applies with the original algebraic arities. This is a new sampler/transcript profile, not byte-identical old Jolt.
2. **Preserve the modulo law, and certify the raw-space extraction.** [DERIVATION] Treat a frontend coordinate as its uniform N-element raw word. A complete tree with L(d)+1 raw-distinct children must contain d+1 distinct decoded residues, because at most L(d) words map to any d residues. Select those children and their complete suffixes to obtain the ordinary degree-d interpolation tree. At a flat affine coordinate d=1, three raw-distinct children suffice to obtain two distinct K values, keeping other coordinates fixed. Thus Lemma3.22 can be applied with raw arity L(d)+1, provided the compiler preserves its required full raw/semantic prefix: a direct sufficient implementation records the consumed raw challenge words in the typed history; if only decoded values are retained, prove the exact quotient-prefix invariance instead of assuming it. Conditioned on a raw coordinate, sampling its tape is trivial; conditioned on a residue, choose uniformly among its one or two raw preimages and retain the correct joint law of the rest of the answer.

For option2 the ledger is

epsilon_A,int <= sum_common L(d)/N + C_new/q^2 + S_A.

Equivalently set C_common,mod=(q/N)sum_common L(d); a simpler safe coefficient is 2 sum_common d, giving the requested C_common,mod/q form. **Tree factors also change:** flat factor 1+sum L(d), nested product of (L(d)+1), not the uniform-K factors. Finite supported-depth and whole-runtime certificates must be recalculated. This raw-space derivation uses existing heterogeneous extraction after an explicit deterministic pruning argument; it is not a claimed theorem for the byte-identical legacy digest/session implementation.

A coupling-to-uniform alternative must retain its per-draw variation Delta_K=r(q-r)/(Nq) multiplied by the actual bounded exposure count, including queried candidate contexts where appropriate; it cannot call that term zero. The direct raw-space accounting above avoids unnecessarily replacing the exact small bad-set mass by the looser total-variation allowance.

Evidence: immutable Jolt crates/jolt-transcript/src/digest.rs:170–182; crates/jolt-field/src/solinas/fp128.rs:1131–1171; FRONTEND_MANIFEST:147–173. No numeric security level is assigned to any of these expressions.

## 7. Reject the legacy one-K-scalar bridge as an automatic handoff proof

The current grouped code absorbs setup/schedule, roles, commitments, points and values, then calls bridged_akita_session. That function draws one K scalar, serializes it and appends it to a session label. A later key identified only by that seed plus the new native instance need not identify the full preceding frontend/archive history. Same seed and same native instance do not prove same earlier history, which is essential to the mixed-tree same-prefix argument. The seed is not a degree-one algebraic test that can simply be charged 1/q and forgotten.

A fresh independently modelled backend oracle can produce full E2 outputs from a short seed; **seed length alone is not a proof that a single backend ROM output is nonuniform**. The actual missing property is full-context binding / same-original-execution and conditional programming across the nested transcript. Neither stretching the seed to 32 bytes nor exporting a digest state proves that property. Reusing the bridge would require a separate nested-FS/compression/collision and extraction-composition analysis with actual resource terms; none of the reviewed mixed-tree instantiations supplies it automatically.

Use a versioned complete-prefix handoff or an already proved chained compiler with all its explicit losses. Bind the exact K/E2 policy, basis, source/view, statement, all prior frontend and earlier update messages/challenges, site/order, and current group ledger. Preserve atomic vectors, independent shell coordinate streams and all exceptional branches. The concrete hash remains a separately disclosed extraction-use assumption, not a proof of injectivity.
