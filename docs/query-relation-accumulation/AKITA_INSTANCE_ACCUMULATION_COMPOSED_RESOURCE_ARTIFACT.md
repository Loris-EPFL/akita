## 5. Specific theorem/artifact prerequisites preventing numerical admission

These are reachable-work findings, not a request to invent constants:

1. **Deterministic composed extraction and ancestor/alias certificates.** The [native supplied-tree theorem](AKITA_INSTANCE_ACCUMULATION_NATIVE_SOURCE_TREE.md) now derives bounded original Main extraction with the retained native prefix. It does not build that tree from H1610 or complete the K frontend/ancestor/alias composition. The K context supplies actual carry origins and branch alternatives but does not itself prove their algebraic degree or semantic alias adequacy.
2. **Exact programmed full-answer law and concrete-model losses.** Akita's primary theorem programs separately indexed ideal coordinate streams. Current inner execution uses the concrete chained H1610 compiler. The ideal paired/chain reduction, its query/runtime translation and cutoffs, conditional tapes for the actual bounded K/E2/shell streams, the revised setup-XOF premise and the concrete native D1 game-preservation loss must be instantiated for this setup/grammar. Concrete sampler uniformity tests cannot establish that theorem. Equal full contexts do not make different fork prefixes equal.
3. **An actual extractor and resource policy.** Akita Eq. (227) states an implementation-dependent polynomial in tree size, adversary time, verifier time and filter work; it explicitly does **not** give exact call counts or universal constants. Eq. (228) adds setup embedding and deterministic collision work to that **whole** extractor runtime. Neither an exact local factor product nor a fixed-degree formal polynomial supplies a concrete value of this runtime. A metered extractor or a separately supplied, justified concrete runtime theorem is needed, together with actual adversary Q/time/memory/auxiliary limits. Do not substitute `Q=2^32` or honest draw counts.
4. **Runtime-priced Module-SIS advantage functions.** For each actual target I the needed term is `Adv_MSIS_I(resources(B_I))`, not an unqualified estimator bit number. The solver runs the entire extractor; repeated segments/aliases/reference comparisons do not divide that runtime by twelve. If hardness only applies to worst-case bounded machines, give a global cutoff L and a proved expected-work bound M, retaining a separate tail `M/L` (or a tighter proven tail). A mere expected-polynomial assertion cannot be substituted into a worst-case runtime assumption. Preserve original-execution failure semantics in any truncation.
5. **External certificate/statement evidence and pricing.** The actual bounded codec, public native verifier, canonical consumed bytes, context/adjacency checks, all native updates/final decider and exact EOF have now passed the two-frame integration. This installation-only audit does not consume that external certificate evidence, so its emitted `native-certificate-statement-codec` prerequisite is not a claim that the implementation is absent. Whole-profile admission still needs the external linkage/grammar/pricing evidence attached to its approved profile; no wrapper is mandatory.
6. **Whole-execution pricing under the selected finite contract.** Expanded definitions and the larger tagged profile above are selected and implemented. Finish the actual complete bounds across every retained transcript/context/seal/frame/record, allocation and source/matrix/verifier operation. The caps alone neither price that work nor prove every declared T16 trajectory fits. Preserve all binding inputs, one compiler, independent mutable continuation state per proof party, and actual global/per-stream abort boundaries.

For an admitted *ideal* inner experiment, the eventual expression has separate terms of the schematic form

\[
(Q_i+1)\left(C_K/q+C_{E2}/q^2+W/M_{shell}\right)
+\delta_{chain}+\delta_{setup}+\delta_{cut}
+\sum_I \mathrm{Adv}_{MSIS,I}(R_I).
\]

Here `M_shell = binom(128,40)·binom(40,24)·2^40`. The audit's declared/local charges cannot yet be substituted as a complete `C_K,C_E2`: the above native prerequisites determine the missing complete relation, exceptional sets and resource translation. The original adversary's Q controls the classical statistical forking loss; queries/work incurred by extraction belong in `R_I`. Do not multiply a matrix-cost estimate by a tree size and claim this is the theorem's exact runtime. Unknown native losses stay missing, not zero. If a wrapper is later selected, its independent tree/query/resource/setup/source terms and derived native-forger resources are additional, separately priced obligations; their current absence is not a native-certificate blocker.

Akita's FS theorem is **classical ROM**. A quantum lattice cost model does not upgrade it to QROM or prove post-quantum noninteractive knowledge soundness. Neither this audit nor the source notes establish performance parity.
