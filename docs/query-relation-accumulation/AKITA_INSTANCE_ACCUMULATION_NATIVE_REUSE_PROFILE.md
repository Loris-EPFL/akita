## 2. Field boundary and pending relation

Let
\[
q=2^{128}-2^{32}+22537,\qquad K=\mathbb F_q,\qquad
E_2=K[U]/(U^2-5),\qquad S=K[Y]/(Y^{128}+1).
\]

The original q128 ordinary configuration permits extension degree one. S is a cyclotomic quotient ring, not a field. E2 is used here for additional scalar-challenge margin, not because lattice commitments intrinsically require a nontrivial extension.

| Complete ordinary outer Jolt/Akita proof | Independent outer K sources/matrices | K | Use ordinary K/K PCS with an admitted actual guest schedule |

At the frontend handoff, map each ordinary point/value `(r,y)` to `(iota(r),iota(y))`, where iota is the canonical K-to-E2 inclusion. For every K-coefficient multilinear polynomial,
\[
f_{E_2}(\iota(r))=\iota(f_K(r)).
\]

No source coefficient, source handle, commitment, decoder, physical address or supplied decommitment changes. Normalize these lifted claims with the E2 raw-domain claims and prior E2 receiver claim **on the same raw source view**. Do not divide by a random terminal factor or replace the raw view by decoded/redecomposed values.

The outgoing object is the existing pending receiver relation, not a complete segment proof. It retains its actual commitment/path, E2 point/value, domain/row metadata, source ownership and continuation state. The final ordinary K/K proof can check an E2 verifier without making its own proof challenges E2. This is arithmetic emulation, not a field reinterpretation.

## 3. Transcript and error policy

Use the bounded exact-uniform sampler specialized to K for **both** the candidate frontend and matched ordinary control. Keep the exact E2 sampler for new accumulation checks. Legacy 16-byte modular reduction is not exactly uniform K and is not inherited silently.

Bind the entire execution context across the frontend/PCS boundary: installation, source/profile identities, field/sampler versions, canonical prior messages, ordered aliases and points, segment index and endpoints. A short session digest is not a substitute for the required same-execution binding/composition certificate. Conversely, a short seed alone does not prove that a fresh independent ideal-oracle E2 answer is nonuniform. These are distinct claims.

For a common adversarial resource convention, the inner statistical ledgers have the form
\[
B_A=(Q+1)\left(\frac{F+A_K}{q}+\frac{A_E}{q^2}+S_A\right),
\qquad
B_R=(Q+1)\left(\frac{F+P_R}{q}+S_R\right).
\]

F includes only genuinely shared frontend/continuation checks. A retained K-only physical-hole or endpoint check belongs in F only when the ordinary control also performs it; otherwise charge A_K or explicitly place that added check in E2. There is no algebraically forced accumulation-only K challenge in the reviewed boundary, but **A_K=0 is an actual-manifest obligation**, not a label. Do not move the earlier whole “new work” subtotal into A_E: it includes continued-frontend work.

Akita's heterogeneous-coordinate tree framework supports the K/E2 split: interpolation arities remain those of the actual polynomials, while the bad-set denominators are q or q squared. Sampler aborts, virtual extraction work, complete setup/MSIS inventories and concrete transcript assumptions remain separate.

### Different shells can satisfy the same comparison policy

A fair control need not use an identical shell. Frozen `GroupCommitPhaseParams` and `CommittedSourceContract` do not contain a consuming shell. `GroupOpeningPlan` does; `GroupOpenPhaseParams::admit` accepts required A/B bounds below the frozen capacities.

Thus an independently admitted ordinary d128 control may use the production shell `(31,0)`, with l1 norm 31, while accumulation uses `(24,16)`, with l1 norm 56. At base32/depth3, the ordinary required A radius is 4,063,108 versus 7,339,808 for the compact accumulator; both fit its frozen rounded cap 8,126,340. Ordinary Main and RAM response magnitudes 1,736 and 7,936 fit the positive depth3 reach 15,855. This does not admit a suffix automatically; rebuild and validate it under the actual shell/basis.

Let
\[
M_A={128\choose40}{40\choose24}2^{40},\qquad
M_R={128\choose31}2^{31}.
\]

If the mixed manifest establishes `A_K=0`, `A_E<=2^40` and the compact shell count is at most 1,992, then
\[
\frac{2^{40}}{q^2}<\frac1q,\qquad
\frac{1992}{M_A}<\frac1{M_R}.
\]

The exact rational ratios are approximately `3.2311743e-27` and `1.1843601e-14`. These are sufficient comparisons of **local upper-bound charges**, not lower bounds on an attack against the control and not total receipt dominance. Each outer workload, schedule, source comparison and derived inner-forger resource bound must still be charged separately. Identical shells remain an optional controlled experiment, not a requirement imposed on the user.

## 4. Shared setup: exact map and reduction

For a view I=(d,n,m), define
\[
M_I(S)[a,b]=\sum_{j=0}^{d-1}
 S[(am+b)d+j]Y^j\pmod{Y^d+1}.
\]

Every view starts at flat coefficient zero and uses **its own row stride**. Different widths are different reshapes, not top-left crops of one largest shaped matrix. F/H use their own d16/d8 rings; reblocking storage is not asserted to be a ring homomorphism.

**Reduction [INFERENCE — specialization of Akita Lemma 10.11].** Fix a target view. Embed an ordinary uniform Module-SIS challenge in its first nmd coefficients; fill the remaining flat coefficients uniformly. The resulting whole S is uniform because the target coefficient map is a bijection. Derive all other views from that same S, preserving every overlap. Run the complete adversary/extractor and retain its output only when it identifies this target. Its nonzero kernel vector has the same ring, width and norm. Sum over the finite target inventory. For setup-adaptive schedule choice, fix the admitted family before setup and run the choice unconditionally, as in Corollary 10.12.

No independent-role assumption is needed. Source uniqueness and backward weak/strong extraction use deterministic per-view collisions. They still require full A/B/F original-source agreement, appropriate fixed D/H agreement within coordinate forks, actual unit denominators, all range/binary/zero checks and the complete final terminal. A shared key does not make commitments perfectly unique or make semantic roles interchangeable.

## 5. Provisioning and authenticated static data

The native-reuse candidate uses the existing seed/page convention, not a fiction that independent role arrays already have native seed provenance. The exact native page framing includes its derivation tag, page size, approved 32-byte seed, field modulus and page index; it excludes matrix role and ring dimension. Each page supplies 4,096 accepted K coefficients. The original q128 `F::random` reads 128-bit little-endian candidates and rejects values at least q.

In the **ideal independent-page stream model**, accepted coefficients are exactly uniform: modular-sampling bias is zero. Rejection probability per draw is less than 2^-96 and affects expansion work. The previous independent-role 512-bit reduction bias formula does not apply. Bounded runtime/cutoff claims must account for actual rejection tails; no unimplemented cap is assumed.

A conditional raw-page simulator can emit geometrically many rejected candidates, each uniform in `[q,2^128)`, before the prescribed uniform accepted coefficient, cache all prefixes, and append independent trailing bytes. This preserves the complete ideal setup experiment while embedding the SIS target. It is not an algorithm for programming concrete SHAKE.

A fixed concrete public-seed SHAKE expansion is not statistically close to a huge uniform flat matrix merely because its field sampler is unbiased. The native setup-XOF idealization/instantiation premise remains explicit, separate from concrete inner/outer Fiat–Shamir premises. The default function named `sample_akita_setup_seed` uses the fixed `DEAD_BEEF_CAFE_BABE` seed; it is **not fresh entropy sampling**. Approve the actual setup and its provenance before source creation; a proof author cannot choose a replacement seed per proof. Inner and outer setup/FS inputs must be injectively domain separated.

Install native material through verified construction/deserialization, or through an explicitly trusted producer whose exact material has already been authenticated. `CpuBackend::new` checks descriptor validity but does not itself rederive every matrix coefficient. A valid seed label or matrix shape is insufficient.

For the final receipt, serialize **one flat S plus canonical view/profile descriptors**, the approved program and checked proof-independent static data in original trusted advice. Authenticate the resulting new `C_static` under the independent outer source map. Do not serialize 33 repeated arrays and still claim the prefix-size saving. Preserve exact consumed bytes, source-reference binding, canonical decoding, no self-authenticating setup, and all [guest C7 obligations](AKITA_INSTANCE_ACCUMULATION_GUEST_SPEC.md). Changing setup law changes the pre-provisioning descriptor and the exact D1-NGP game; its assumption and resource translation must be restated for this installation, not inherited from the independent-role experiment.

Fresh sources must be created under the shared installation from the outset. Existing independent-key commitments cannot be relabeled or recommitted to evade this rule. Current import recomputes and compares both public commitment and retained path under the receiving setup; keep that check and immutable original-plane storage.
