## Physical Main checks close the old zero-row kernel

The semantic affine reconstruction for every nonRAM family is

`R_c(a,t)=X_c(a,t)` for a!=0, and `R_c(0,t)=1-sum_(a!=0) X_c(a,t)`.

RAM uses R_c=X_c. The corresponding off-cube formula is `R_c(r,t)=eq(r,0)+sum_a (eq(r,a)-eq(r,0))*X_c(a,t)`. Balanced digit decode has d(0)=0. Consequently semantic Booleanity alone cannot see X_c(0,t); the historical physical-zero counterexample remains valid for bare prepare/prepare_native.

The implementation separates inactive and active address-zero masks exactly. Main is bound before tau/alpha. If any masked coefficient is nonzero, one selected column's multilinear equality transform is nonzero.
