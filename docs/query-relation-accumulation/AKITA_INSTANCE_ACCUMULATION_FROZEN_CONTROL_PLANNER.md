ANCHOR AND RESULT
The invariant is the exact ordered original Main/RAM committed profiles AND their original source declarations/handles. Changing the consuming shell is allowed; changing A/B geometry, matrix identity, source planes, or source ownership is not. The preferred performance control is a complete ordinary K/K FoldSchedule using the NATIVE coefficient-packing k=1,h=1 identity path for the original Main/RAM root, followed by the full native permitted suffix/terminal domain. It must include the complete terminal response and exact grinding ledger, or report bounded-domain rejection. Root ET and all-ET are alternative diagnostic designs, not the default baseline.

No existing public planner entry freezes the exact final source profile. Add an entry using EXISTING CommittedGroupBatchProfile and a frozen-final admission/materialization branch, not merely an equality filter. Native root coefficient packing k1,h1 is already admitted by planner geometry and runtime execution rules; it avoids the root-ET enumeration and validator exceptions described as an alternative below. Offline generation does not depend on shared-setup backend storage. This revision supersedes both earlier ET defaults: parent requested preserving the original k1,h1 packing path after it was confirmed to support query-derived partials directly from original planes.

* Root guidance also fixes the root dimension tuple, opening/challenge, inner/opening bases, block split and slice count before generation (candidates.rs:250-269,380-419,442-452,586-616,836-851). The adaptation guide freezes suffix topology/depth and structural choices, rebuilding length/security-derived values.
* Crucial obstruction: root_final_group_level_params_candidate always calls derive_ab_commitment_candidate (planner.rs:503-583), which selects the newly required A norm and calls InnerCommitMatrixParams::try_new_with_min_rank (candidate.rs:189-205); B is then derived from that minimum A rank (candidate.rs:263-274). Root equality runs only AFTER this derivation. It cannot inject the supplied larger rank or larger audited norm capacity. A supplied rank-3/radius-8126340 Main can therefore be rejected despite valid capacity if the ordinary shell has a smaller derived minimum. Removing the equality check would silently change the commitment. A new source-profile constraint that ONLY filters normal candidates is insufficient.
* There is also an independent source/consumer coupling: the normal root builder sets B digits to the consuming log_basis_open (planner.rs:524-528,636-638). A frozen B owns its own basis/depth; admission allows consuming basis >= frozen B basis if the bound covers it. Frozen materialization must preserve the supplied B, not regenerate it.
* Additional blocking seam: suffix_dp/candidates.rs:40-49 classifies early EvaluationTrace as TerminalOnly or absent, never FoldOnly/TerminalAndFold. Combined with early_packing_level = state.level <= 1 (:242), it generates no EvaluationTrace root fold at all, including K/K. Merely filtering packing would leave no root. Separately, akita-params/src/schedule.rs:925-939 sets packing_required = absolute_level <= 1 without consulting extension_degree; ResolvedScheduleRow::try_new calls that execution validator before semantic audit. Current early nonterminal suffix level1 is packing-only, levels>=2 are ET-only, and ordinary terminal is ET-only (schedule.rs:292-300). These are not freely interchangeable choices in current code.
